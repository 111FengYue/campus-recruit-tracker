# 校招记录 · Campus Recruit Tracker

一个可直接在浏览器打开的单文件校招进度记录工具，界面简洁，数据保存在浏览器本地（localStorage），无需安装任何东西。

## 功能

- 记录岗位的**公司名**、**岗位名**、**日期**和**当前进展**
- 按进展自动分组显示（已投递 → 简历筛选 → 笔试 → 面试 → Offer → 已签约 …）
- 落选岗位一键**划掉**（勾选「落选」）
- 点击岗位展开「**需要学习的知识点**」，可添加 / 删除 / 勾选已掌握
- **导出 / 导入 JSON** 文件备份
- **深浅色模式**切换

## 使用方法

直接双击打开 `index.html` 即可使用。

> 数据保存在当前浏览器的本地存储中，**不会跨设备或跨浏览器同步**。换设备前请先用右上角「导出」备份成 JSON 文件，再在新设备「导入」。

## 部署

这是一个纯静态页面，可部署到任意静态托管平台，例如 GitHub Pages：

1. 仓库 Settings → Pages → Source 选择 `main` 分支根目录 → Save
2. 稍等片刻即可通过 `https://<用户名>.github.io/campus-recruit-tracker/` 访问

> 注意：部署后数据仍存在每个访问者各自的浏览器中，互不影响。
